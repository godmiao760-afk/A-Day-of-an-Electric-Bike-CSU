## 1. v2 一天的流程

```
Intro ──（过夜后饥饿 ≤ 0）──→【昏倒】
  ↓
FindCar（挪车可能带倒一排）→ Node 校门口 → Ride（交警：停 / 闯）→ Park
  → Class 上午（判上午迟到，扣饥饿）
  → Node 中午（每个选项都花时间）
  → Class 下午（判下午迟到，扣饥饿；第 5 天到这里 → 最终结局）
  → Node 傍晚 → Charge（插上就看运气）→ Result（今日评价）→ Intro 下一天

随时：钱 ≤ 0 →【没钱】；硬闯被抓 →【派出所】；上课扣饥饿后 ≤ 0 →【昏倒】
```

## 2. 结局

| 结局 | key | 条件 | 什么时候判定 | 画面 |
|---|---|---|---|---|
| 完美 | `perfect` | 5 天迟到 0 次 | 第 5 天下午课结束 | 主角 |
| 合格 | `pass` | 迟到 1–5 次 | 同上 | |
| 不合格 | `fail` | 迟到 ≥ 6 次 | 同上 | |
| 隐藏 1 派出所 | `police` | 碰到交警硬闯，被抓 | 当场 | 被带进派出所 |
| 隐藏 2 昏倒 | `faint` | 饥饿 ≤ 0 | 上课扣完饥饿后；第二天早上过夜扣完后 | 人物昏倒 |
| 隐藏 3 没钱 | `broke` | 钱 ≤ 0 | 任何扣钱之后，当前弹窗关掉时 | 跪在地上嚎啕大哭 |

- **迟到次数**：上午、下午各算一次，一天最多 2 次，5 天最多 10 次。
- **同时满足多个时**：派出所 > 昏倒 > 没钱 > 最终三结局。
- **新场景 Ending**：新文件 `src/scenes/Ending.js`，场景 key `'Ending'`，用 `UI.fadeTo(this, 'Ending', { key: 'broke' })` 进入（结局 key 走 data，不新增 GameState 字段）。显示结局图（没图用色块）、标题、一段描述、统计（第几天、迟到次数、硬闯成功次数、余额）。F / R 都是 `newGame()` 回 Intro。
- **第 5 天**：下午课结束直接进最终结局，不再有傍晚、充电、结算。天数放在 `CONFIG.ending.totalDays`。
- **原来的 4 个"结局"**（「难得顺利的一天」等）改叫**今日评价**，每天在 Result 照样显示，不影响最终结局。`LINES.endings` 的 key 不变。
- **Intro** 每天多显示一行「已迟到 N 次」。
- **预兆**（防止玩家觉得莫名其妙）：
  - 饥饿 < 15：独白「眼前发黑……」
  - 钱 < 20：HUD 上的钱变红
  - 硬闯成功：独白「交警好像记住我的车了……」
- **演示**：`CONFIG.ending.totalDays` 改成 3 就是 3 天制；想直接看结局，用 `DEBUG_STATE = { day: 5, lateCount: 3 }`。

## 5. 每项改动细节

### 5.1 骑行时车不再穿模（A，Ride.js）

**原因**：现在只判"玩家 ↔ 车"，车和车之间不判；各类车速度不同（外卖 340、汽车 90、校车 50 同向，逆行 140 迎面，行人横穿），生成时也不看车道上有没有车，所以会叠在一起。

**做法**：不开车车之间的物理碰撞（会互相推开，更乱），改成按车道的简单交通规则，每帧检查：

| 情况 | 处理 |
|---|---|
| 生成时出生点附近（`followGap` 内）已有车 | 换一条道；四条都有就这次不生成 |
| 汽车 / 校车追上同道前车 | 减速到前车速度，排队 |
| 外卖车追上同道前车 | 换到旁边的空道超车（可能并进玩家的道，更刺激） |
| 逆行车迎面碰上同道车 | 往旁边空道躲；躲不开就停下 |
| 行人横穿，前方有车快到 | 在路边等一下再走 |

- 数值：`ride.followGap`。
- 注意：排队会堵住车道，D 要重新试 `spawnEvery`。

### 5.2 骑行最快速度加快（D，只改 config）

| key | 现在 | 改成 |
|---|---|---|
| `ride.speed` | 200 | 240 |
| `ride.sideSpeed` | 180 | 200 |

- 外卖车速度是 `speed × 1.7`，会跟着变快（340 → 408）。
- 耗电按**骑行时间**算，开得快会更省电，所以要和 5.9 的耗电一起调。
- 顺手修（A）：Ride 里 `Phaser.Math.Linear(this.vy, target, rate)` 是按帧算的，144Hz 屏幕起步比 60Hz 快一倍多。改成和 `delta` 挂钩，换电脑演示手感才一致。

### 5.3 早高峰"单行道"路段（A，Ride.js）

**理解**：早高峰大家都往教学楼冲，整条路只剩一个方向在走，对面来的只能逆行挤过来，所以逆行车变多，而且哪条道都有。

**做法（路段事件，和大坡一样）**：
- 每天每条路线各掷一次 `ride.oneWay.chance`，决定今天堵不堵。
- 堵的话，路程 `oneWay.range`（30%–70%）这一段：
  - 路边显示「早高峰 · 被挤成单行道」，进入时独白提醒；
  - 逆行车权重 × `wrongMul`（3）；
  - 逆行车出现在玩家这条道的概率从 0.5 提到 `sameLaneChance`（0.8）。
- 校门口选路线时透露一句：「听说校内那条路今天挤成单行道了」，选路线多一层考虑。
- 今天堵不堵只在 Ride / Node 里用，存成 Ride 场景内部变量即可；要在校门口透露，就在 Node gate 里掷好，通过 `UI.fadeTo(this, 'Ride', { oneWay: true })` 传过去，不新增 GameState 字段。

**文案**（lines.js 的 ride / gate 里）：`oneWaySign`、`oneWayEnter`、`oneWayRumorInside`、`oneWayRumorOutside`。

### 5.4 充电去掉"守着"（B，Charge.js）

- 插上桩 = 原来的"先回宿舍"：`gambleWinRate` 充满（`'full'`），否则只 +`unpluggedGain`（`'unplugged'`），然后直接进 Result → 第二天。
- 不再弹二选一，结果**不当场揭晓**：独白「插上了，回去睡觉。」，第二天 Intro 再说「满电！」或「线又被拔了」（lines 里这两句本来就带"（第二天早上）"）。
- 去掉稳妥选项后电量全看运气，建议 `gambleWinRate` 0.5 → 0.6，`unpluggedGain` 20 → 30。
- 要清理：`chargeResult` 的 `'watch'`、`CONFIG.charge.watchPerMinute`、`LINES.charge.question` / `watchDone`、Result.js 里 `watch: '守着充'`。

### 5.5 宿舍楼下找车也有多米诺（B，FindCar.js）

- **触发**：**挪开邻车时**按 `findCar.dominoChance` 带倒同一排，往远离自己车的方向倒，最多 `dominoMax` 辆。走路蹭到车**不**触发（车阵里经常蹭到，太烦）。
- 倒着的车按 F 扶起，每辆 +`findCar.liftMinutes`；**全部扶起来才能解锁**自己的车。
- 代码照搬 Park.js 的 `bump / hasFallen / nearestFallen / liftBike`；FindCar 本来就有 `this.grid[排][列]`，直接用。
- 文案可以复用 `LINES.park.domino / lift / liftFirst / liftHint / liftedAll`，想区分再在 `findCar` 下加。

### 5.6 碰到交警：停车受检 / 硬闯（A，Ride.js、NodeScene.js）

**触发**：校外骑行到检查点、去后湖碰到交警时，先弹二选一（不再直接检查）：

| 选项 | 结果 |
|---|---|
| 停车接受检查 | 和现在一样：`policeCheck()`，没头盔 / 没牌照 / 载人各罚一笔，被罚耽误时间，载人被罚同学跑掉 |
| 硬闯过去 | 按 `runCatchChance()` 掷：**被抓 → 隐藏结局「派出所」**；闯过去 → 不罚款、不耽误时间、`runs + 1`，载的同学不跑、照样给钱 |

- **被抓概率**：`runCatchBase + runs × runCatchStep`，最多 `runCatchMax`（0.3 → 0.45 → 0.6 …）。越闯越容易被抓，第一次闯大多能过。
- 第 1 天新手教学：检查点照样出现，也给这个选择。
- 硬闯成功独白：「交警好像记住我的车了……」（预兆）。
- 这改掉了之前定的"载人碰到交警必罚、同学必跑"：现在是**停车受检**才必罚。
- `policeCheck()` 不变；新增 `runCatchChance()` 放在 state.js。

**文案**（lines.js 的 police 下）：`askStop`（二选一的问题）、`optStop`、`optRun`、`runOk`、`runOmen`。

### 5.7 5 天制 + 6 个结局（A）

**判定放在 state.js，跳转放在场景里**：

```js
// state.js：只算，不跳场景
hiddenEndingKey()   // 'faint'（饥饿 ≤ 0）| 'broke'（钱 ≤ 0）| null，昏倒优先
finalEndingKey()    // lateCount 为 0 → 'perfect'；≤ passMaxLate → 'pass'；否则 'fail'

// 场景里：弹窗关掉 / 扣完之后检查一次
const k = hiddenEndingKey();
if (k) { UI.fadeTo(this, 'Ending', { key: k }); return; }
```

**检查点**：

| 位置 | 查什么 |
|---|---|
| Intro `create()`（过夜扣饥饿之后） | `hiddenEndingKey()` |
| Class 上午 / 下午（扣完饥饿、判完迟到之后） | `hiddenEndingKey()`；第 `totalDays` 天下午 → `finalEndingKey()` |
| Ride 交警弹窗关掉后、Park 贴条弹窗关掉后 | `hiddenEndingKey()`（罚款可能扣到 ≤ 0） |
| NodeScene 每个选项 `finish()` 之前 | `hiddenEndingKey()` |
| Charge `finish()` 之前 | `hiddenEndingKey()`（扫码 ¥2 可能正好扣到 0） |
| Ride / Node 硬闯被抓 | 直接 `{ key: 'police' }` |

- **菜单提示**：选项花完钱会 ≤ 0 时，label 后面加 `LINES.meals.lastMoney`「（买完就身无分文了）」，不置灰，让玩家自己选。
- **第 1 天最坏情况**：载人 + 没头盔 + 没牌照 + 停车受检（罚 80）+ 门口违停被贴条（罚 20），100 块正好花光，早上就进「没钱」结局。几件事要同时发生，保留当彩蛋。
- **文案**：`LINES.finalEnding = { perfect: { title, text }, pass: …, fail: …, police: …, faint: …, broke: … }`。和每日评价 `LINES.endings` 区分开，名字别弄混。
- **注册场景**：index.html 在 Result.js 后面加 `Ending.js`；main.js 的 `GAME_SCENES` 加 `Ending`；CLAUDE.md 第 4 节文件表加一行。

### 5.8 下午也会迟到（A，NodeScene.js、Class.js）

- 下午课 `afternoonClass` = 14:00。中午 12:00 开始，**每个选项花时间**，走完 `clock` 晚于 14:00 → 下午迟到。
- 不加新玩法，演示时长不变。

| 中午选项 | 花的时间 `minutes` | 下午迟到概率 |
|---|---|---|
| 食堂 | 40–60 分钟 | 不会 |
| 不吃 | 0 | 不会 |
| 后湖 | 90–130 分钟 | 约 25%；被交警罚了再 +10 分钟，约 50% |
| 办牌照 | 100–140 分钟 | 约 50% |

- 选项 label 上显示大概要多久，比如「后湖（约 2 小时）」，玩家能权衡。
- **Class 下午**开头：`clock > afternoonClass` → `latePM = true`、`lateCount + 1`，显示「到教室时间 14:10 —— 迟到了」，然后照常扣饥饿、电量，时钟跳到 17:30。
- **Class 上午**：`late` 为 true 时 `lateCount + 1`（`late` 的判定照旧在 Ride / Park 里）。
- 傍晚选项也会加时间，但不影响任何东西（Charge 开场会把时钟设到 22:40）。
- **Result** 的"停好车时间"一行后面加「下午：准时 / 迟到」，再加一行「累计迟到 N / 10 次」。

### 5.9 数值（D，只改 config）

**饥饿**（让"少吃一顿"不至于饿晕）：

| key | 现在 | 改成 |
|---|---|---|
| `hunger.start` | 70 | 80 |
| `hunger.perClass` | 35 | 25 |
| `hunger.overnight` | 20 | 15 |

| 吃法 | 结果 |
|---|---|
| 每天两顿食堂 | 饥饿保持在 55–100，不会饿 |
| 少吃一顿（比如中午办牌照） | 最低 30，不会晕 |
| 一整天不吃 | 第二天早上开始饿、走得慢，上午课晕倒 |
| 每天只吃一顿食堂 | 第 3–4 天晕倒 |
| 每天只吃一顿后湖 | 能撑住 |

**演示时长**（目标 5 天 5–10 分钟，一天 ≤ 2 分钟；现在一天约 3 分钟）：

| key | 现在 | 改成 | 效果 |
|---|---|---|---|
| `ride.speed` / `sideSpeed` | 200 / 180 | 240 / 200 | 即 5.2 |
| `ride.routes.inside.length` | 12000 | 7200 | 骑一趟 60 秒 → 约 33 秒 |
| `ride.routes.outside.length` | 6500 | 4000 | 32 秒 → 约 17 秒 |
| `ride.drainFlat` / `drainSlope` | 0.45 / 1.0 | 0.8 / 1.8 | 每趟耗电和现在差不多（校内约 35%，校外约 13%） |
| `timeScale` | 10 | 15 | 早上迟到难度基本不变；充电 120 秒 → 80 秒 |
| `findCar.rows` / `cols` | 5 / 10 | 4 / 8 | 找车更快 |
| `charge.gambleWinRate` / `unpluggedGain` | 0.5 / 20 | 0.6 / 30 | 即 5.4，去掉"守着"后补一点 |

- 路短了，被撞的机会也少一半，靠 5.3 的单行道路段把难度补回来。
- 熟练的人一天约 2 分钟，5 天 8–10 分钟。评委第一次玩会慢一些，时间不够就用 `DEBUG_STATE = { day: 5, lateCount: 3 }` 从第 5 天开始。
