# 小电驴的一天 · 项目说明

## 玩法概览

- 一局 **5 天**（`CONFIG.ending.totalDays`），每天：找车 → 骑车上学 → 停车 → 上午课 → 中午 → 下午课 → 傍晚 → 晚上充电 → 今日评价。第 5 天下午课结束直接进最终结局。
- 演示时长：熟练的人一天约 2 分钟，5 天 **5–10 分钟**。时间不够就用 `DEBUG_STATE = { day: 5, lateCount: 3 }` 从第 5 天开始。
- **迟到**：上午停好车晚于 8:00、下午到教室晚于 14:00 各算一次（中午每个选项都花时间，后湖、办牌照可能拖到下午迟到），累计进 `lateCount`，一天最多 2 次。
- **6 个结局**：

| 结局 | 条件 |
|---|---|
| 完美 | 5 天迟到 0 次 |
| 合格 | 迟到 1–5 次 |
| 不合格 | 迟到 ≥ 6 次 |
| 隐藏 · 派出所 | 碰到交警硬闯，被抓 |
| 隐藏 · 昏倒 | 饥饿 ≤ 0 |
| 隐藏 · 身无分文 | 钱 ≤ 0（跪地大哭） |

- **v2 新机制**：
  - 交警：碰到先二选一「停车接受检查」（照旧罚款）/「硬闯过去」（被抓进派出所；闯过去不罚款，但每闯成功一次下次被抓概率 +15%）。校外骑行和去后湖都会碰到。
  - 充电：插上桩就回宿舍睡觉（没有"守着"了），充没充满第二天早上 Intro 揭晓。
  - 早高峰单行道：校门口会听到"哪条路挤成单行道了"，骑到那一段逆行车明显变多。
  - 宿舍楼下找车：挪开邻车时可能带倒一排，全部扶起来才能解锁自己的车。
  - 车和车不再穿模：汽车 / 校车排队，外卖车变道超车，逆行车躲让。
- 每天 Result 的 4 种"今日评价"照旧显示，不影响最终结局。

- 文件名和清单里的名字一样，尺寸照表，车头朝上
- 每放好一个，就把清单里对应的 `file` 改成 `true`，刷新浏览器就能看到
- 只改 `assets.js` 这一个代码文件

### D：数值、文案、测试

- 用 `DEBUG_START` 直接进某个场景，一个个测，发现 bug 就告诉 A 或 B
- 目标：一天约 2 分钟、5 天 5–10 分钟；每天 4 种今日评价、6 个结局都能打出来

## 场景流程与交接

```
Boot → Intro → FindCar → Node{gate} → Ride {oneWay} ─┬─ 到达 → Park {pushing:false} ─┐
                                                     └─ 没电 → Park {pushing:true}  ─┤
   Class{morning} ←──────────────────────────────────────────────────────────────────┘
   → Node{noon} → Class{afternoon} ─┬─ 第 1–4 天 → Node{evening} → Charge → Result → [F] Intro {lastCharge}（第二天）
                                    └─ 第 5 天 → Ending {key: perfect / pass / fail}

   随时：饥饿 ≤ 0 → Ending{faint}；钱 ≤ 0 → Ending{broke}；硬闯被抓 → Ending{police}
   Ending → [F] newGame() → Intro
```

- **Node** 是选择节点（NodeScene.js，场景 key `'Node'`），一个场景三种用法：
  - `gate` 校门口：掷今天两条路是否挤成单行道并透露给玩家；同学求搭车（答应就只能走校外），选校内 / 校外路线
  - `noon` 中午：食堂 / 后湖 / 办牌照 / 不吃（每个选项都花时间，影响下午迟到）
  - `evening` 傍晚：食堂 / 后湖 / 不吃
- 每个事件的触发条件和数值见 **事件流程.md**。

| 场景 | 谁写 | 结束时更新的数据 | 下一个场景 |
|---|---|---|---|
| Intro | A | 不写；第 2 天起先查饥饿 / 钱 | FindCar；饥饿 ≤ 0 / 钱 ≤ 0 → Ending |
| FindCar | B | `clock`、`findCarMinutes`；挪车带倒一排要扶起来，扶车加 `clock` | Node{gate} |
| Node{gate} | A | `route`、`passenger` | Ride（传 `{ oneWay }`：今天这条路堵不堵） |
| Ride | A | `battery`、`hp`、`hits`、`falls`、`clock`；停车受检写 `fines`、`money`；硬闯成功 `runs + 1`；送到同学写 `earned`、`money` | Park（没电时传 `{ pushing: true }`，推车进场，`late = true`）；硬闯被抓 → Ending{police}；罚到钱 ≤ 0 → Ending{broke} |
| Park | B | `arriveClock`；停好的时间晚于 8:00 就把 `late` 设为 `true`；扶倒下的车加 `clock`；门口违停被贴条写 `fines`、`money` | Class{morning}；贴条罚到钱 ≤ 0 → Ending{broke} |
| Class{morning} | A | `late` 为 true → `lateCount + 1`；饥饿减 `perClass`，时间跳到 12:00 | Node{noon}；饥饿 / 钱 ≤ 0 → Ending |
| Node{noon} | A | `clock`（加选项花的分钟）、`money`、`spent`、`hunger`、`meals`、`items.license`；去后湖扣电、可能碰到交警（停 / 闯） | Class{afternoon}；钱 ≤ 0 → Ending{broke}；硬闯被抓 → Ending{police} |
| Class{afternoon} | A | 晚于 14:00 到 → `latePM = true`、`lateCount + 1`；饥饿减 `perClass`，电量减 `dayDrain`，时间跳到 17:30 | Node{evening}；第 5 天 → Ending{perfect / pass / fail}；饥饿 / 钱 ≤ 0 → Ending |
| Node{evening} | A | 同中午（没有办牌照） | Charge；钱 ≤ 0 / 硬闯被抓 → Ending |
| Charge | B | `chargeResult`、`chargeGain`、`battery`、`money`；时间从 22:40 开始，23:00 门禁；插上就定结果，不当场揭晓 | Result；扫码扣到钱 ≤ 0 → Ending{broke} |
| Result | A | 不写；按"上午有没有迟到"和"电量是否 ≥ `chargedThreshold`"显示 4 种今日评价之一，外加下午 / 累计迟到 | F：`nextDay()` 回 Intro（传 `{ lastCharge }`，第二天揭晓充电结果）；R：`newGame()` 重来 |
| Ending | A | 不写；按 `{ key }` 显示结局图、标题、描述、统计 | F / 点击：`newGame()` 回 Intro |

**今日评价**（每天 Result 显示，不影响最终结局）对应 `lines.js` 里的 `endings`：`ontime_charged`、`ontime_empty`、`late_charged`、`late_empty`。
**6 个结局**对应 `lines.js` 里的 `finalEnding`：`perfect`、`pass`、`fail`、`police`、`faint`、`broke`。两组名字别弄混。

## GameState 字段

字段名和含义不许改。要新增字段，先在群里说，由 A 改 `state.js`，并同步更新下表和 CLAUDE.md。

| 字段 | 含义 | 谁写入 |
|---|---|---|
| `day` | 第几天 | `newGame()` / `nextDay()` |
| `clock` | 游戏内时间，单位"分钟"，可带小数（455 = 7:35） | 所有场景（`UI.tickClock`）、Class、Node（选项花的时间）、交警 |
| `clockPaused` | 弹窗时为 `true`，时钟暂停 | `UI` |
| `battery` | 电量 0–100，跨天保留 | Ride、Node（后湖）、Class、Charge |
| `hp` | 血量，只在 Ride 使用 | Ride |
| `late` | 上午是否迟到 | Park、Ride（没电） |
| `hits` | 被撞次数 | Ride |
| `falls` | 摔倒次数 | Ride |
| `findCarMinutes` | 找车用了几分钟 | FindCar |
| `arriveClock` | 停好车的时刻 | Park |
| `chargeResult` | `'none'` \| `'noMoney'` \| `'full'` \| `'unplugged'` | Charge |
| `chargeGain` | 今晚充进去多少电 | Charge |
| **跨天保留** | | |
| `money` | 钱，可以为负（欠款）；≤ 0 进"身无分文"结局 | Node、Ride、Park、Charge、`nextDay()` |
| `hunger` | 饱腹度 0–100，低于 `hungryBelow` 算饿，移动变慢；≤ 0 进"昏倒"结局 | Node、Class、`nextDay()` |
| `items` | `{ helmet, license }` 有没有头盔 / 牌照 | Node（办牌照） |
| `helmetOn` | 头盔戴上没有 | 背包（`UI.backpack`） |
| `lateCount` | 本局累计迟到次数（上午、下午各算一次），决定最终结局；`newGame()` 清 0 | Class |
| `runs` | 硬闯交警成功的次数，越多下次越容易被抓；`newGame()` 清 0 | Ride、Node（`tryRun()`） |
| **每天重置** | | |
| `latePM` | 今天下午迟到没有 | Class{afternoon} |
| `route` | `'inside'` 校内 \| `'outside'` 校外 | Node{gate} |
| `passenger` | 是否载着同学 | Node{gate}、Ride |
| `policeToday` | 今天有没有交警（第 1 天必有，之后随机）；有的话校外骑行 / 每次去后湖再各自按 `police.encounterChance` 掷是否碰上 | `resetDay()` |
| `fines` | 今天的罚款 `[{ reason, amount }]`（交警 + 门口违停贴条） | `policeCheck()`、Park |
| `earned` / `spent` | 今天赚 / 花的钱（花销不含罚款） | Ride / Node、Charge |
| `meals` | 今天吃了哪些 `['食堂', '后湖']` | Node |

- 结局 key 不存进 GameState，走 `UI.fadeTo(this, 'Ending', { key })`；今天哪条路是单行道也不存，走 `UI.fadeTo(this, 'Ride', { oneWay })`。

## 协作规矩
- 每人只改自己的文件，避免 git 冲突。
- 气泡、提示、弹窗、切场景、音效都用 `ui.js` 里现成的函数，不要在场景里自己重写：
  - `UI.setup(this)`：每个场景 `create()` 第一行
  - `if (UI.blocked(this)) return;`：每个场景 `update()` 开头
  - `UI.say` 独白气泡、`UI.hint` 底部提示、`UI.choice` 二选一弹窗
  - `UI.fadeTo` 切场景、`UI.sfx` 音效
  - `UI.createClock` / `UI.tickClock` 时钟、`UI.createHud` / `UI.updateHud` 电量和血量
  - 判断按 F 用 `UI.pressedF(this)`，不要直接用 `JustDown`
