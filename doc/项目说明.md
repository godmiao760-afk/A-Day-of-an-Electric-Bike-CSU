# 小电驴的一天 · 项目说明

## 四人分工

### A：主程序（框架 + 晚上流程）
- 负责：`main.js`、`state.js`、`ui.js`、`scenes/Boot.js`、`scenes/Intro.js`、`scenes/Ride.js`、`scenes/NodeScene.js`、`scenes/Class.js`、`scenes/Result.js`（均已完成，与 CLAUDE.md 第 4 节一致）
- 管理 GameState 字段，负责合并代码
- 演示前把 `main.js` 里的 `DEBUG_START` 改回 `null`

### B：玩法程序（早上流程 + 充电）
- `scenes/FindCar.js`：找车
- `scenes/Park.js`：停车（含多米诺、门口违停）
- `scenes/Charge.js`：充电

### C：美术和音效
- 按 `assets.js` 的清单做 19 张图和 7 个音效
- 图放 `assets/img/`（png），音效放 `assets/sfx/`（mp3）
- 文件名和清单里的名字一样，尺寸照表，车头朝上
- 每放好一个，就把清单里对应的 `file` 改成 `true`，刷新浏览器就能看到
- 只改 `assets.js` 这一个代码文件

### D：数值、文案、测试
- `config.js` 只改数字，`lines.js` 只改文字
- 用 `DEBUG_START` 直接进某个场景，一个个测，发现 bug 就告诉 A 或 B
- 目标：一次骑行大约 60 秒，4 种结局都能打出来

## 场景流程与交接

```
Boot → Intro → FindCar → Node{gate} → Ride ─┬─ 到达 → Park {pushing:false} ─┐
                                            └─ 没电 → Park {pushing:true}  ─┤
   Class{morning} ←─────────────────────────────────────────────────────────┘
   → Node{noon} → Class{afternoon} → Node{evening} → Charge → Result → [F] Intro（第二天）
```

- **Node** 是选择节点（NodeScene.js，场景 key `'Node'`），一个场景三种用法：
  - `gate` 校门口：同学求搭车（答应就只能走校外），选校内 / 校外路线
  - `noon` 中午：食堂 / 后湖 / 办牌照 / 不吃
  - `evening` 傍晚：食堂 / 后湖 / 不吃
- 每个事件的触发条件和数值见 **事件流程.md**。

| 场景 | 谁写 | 结束时更新的数据 | 下一个场景 |
|---|---|---|---|
| FindCar | B | `clock`、`findCarMinutes` | Node{gate} |
| Node{gate} | A | `route`、`passenger` | Ride |
| Ride | A | `battery`、`hp`、`hits`、`falls`、`clock`；交警检查写 `fines`、`money`；送到同学写 `earned`、`money` | Park（没电时传 `{ pushing: true }`，推车进场，`late = true`） |
| Park | B | `arriveClock`；停好的时间晚于 8:00 就把 `late` 设为 `true`；扶倒下的车加 `clock`；门口违停被贴条写 `fines`、`money` | Class{morning} |
| Class{morning} | A | 饥饿减 `perClass`，时间跳到 12:00 | Node{noon} |
| Node{noon} | A | `money`、`spent`、`hunger`、`meals`、`items.license`；去后湖扣电、可能被交警查 | Class{afternoon} |
| Class{afternoon} | A | 饥饿减 `perClass`，电量减 `dayDrain`，时间跳到 17:30 | Node{evening} |
| Node{evening} | A | 同中午（没有办牌照） | Charge |
| Charge | B | `chargeResult`、`chargeGain`、`battery`、`money`；时间从 22:40 开始，23:00 门禁 | Result |
| Result | A | 按"有没有迟到"和"电量是否 ≥ `chargedThreshold`"选 4 种结局之一 | F：`nextDay()` 回 Intro；R：`newGame()` 重来 |

4 种结局对应 `lines.js` 里的 `endings`：`ontime_charged`、`ontime_empty`、`late_charged`、`late_empty`。

## GameState 字段

字段名和含义不许改。要新增字段，先在群里说，由 A 改 `state.js`，并同步更新下表和 CLAUDE.md。

| 字段 | 含义 | 谁写入 |
|---|---|---|
| `day` | 第几天 | `newGame()` / `nextDay()` |
| `clock` | 游戏内时间，单位"分钟"，可带小数（455 = 7:35） | 所有场景（`UI.tickClock`）、Class、交警 |
| `clockPaused` | 弹窗时为 `true`，时钟暂停 | `UI` |
| `battery` | 电量 0–100，跨天保留 | Ride、Node（后湖）、Class、Charge |
| `hp` | 血量，只在 Ride 使用 | Ride |
| `late` | 是否迟到 | Park、Ride（没电） |
| `hits` | 被撞次数 | Ride |
| `falls` | 摔倒次数 | Ride |
| `findCarMinutes` | 找车用了几分钟 | FindCar |
| `arriveClock` | 停好车的时刻 | Park |
| `chargeResult` | `'none'` \| `'noMoney'` \| `'watch'` \| `'full'` \| `'unplugged'` | Charge |
| `chargeGain` | 今晚充进去多少电 | Charge |
| **跨天保留** | | |
| `money` | 钱，可以为负（欠款） | Node、Ride、Charge、`nextDay()` |
| `hunger` | 饱腹度 0–100，低于 `hungryBelow` 算饿，移动变慢 | Node、Class、`nextDay()` |
| `items` | `{ helmet, license }` 有没有头盔 / 牌照 | Node（办牌照） |
| `helmetOn` | 头盔戴上没有 | 背包（`UI.backpack`） |
| **每天重置** | | |
| `route` | `'inside'` 校内 \| `'outside'` 校外 | Node{gate} |
| `passenger` | 是否载着同学 | Node{gate}、Ride |
| `policeToday` | 今天有没有交警（第 1 天必有，之后随机）；有的话校外骑行 / 每次去后湖再各自按 `police.encounterChance` 掷是否碰上 | `resetDay()` |
| `fines` | 今天的罚款 `[{ reason, amount }]`（交警 + 门口违停贴条） | `policeCheck()`、Park |
| `earned` / `spent` | 今天赚 / 花的钱（花销不含罚款） | Ride / Node、Charge |
| `meals` | 今天吃了哪些 `['食堂', '后湖']` | Node |

## 协作规矩
- 每人只改自己的文件，避免 git 冲突。
- 气泡、提示、弹窗、切场景、音效都用 `ui.js` 里现成的函数，不要在场景里自己重写：
  - `UI.setup(this)`：每个场景 `create()` 第一行
  - `if (UI.blocked(this)) return;`：每个场景 `update()` 开头
  - `UI.say` 独白气泡、`UI.hint` 底部提示、`UI.choice` 二选一弹窗
  - `UI.fadeTo` 切场景、`UI.sfx` 音效
  - `UI.createClock` / `UI.tickClock` 时钟、`UI.createHud` / `UI.updateHud` 电量和血量
  - 判断按 F 用 `UI.pressedF(this)`，不要直接用 `JustDown`
