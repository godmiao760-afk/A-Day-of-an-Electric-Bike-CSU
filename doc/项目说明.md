# 小电驴的一天 · 项目说明

## 四人分工

### A：主程序（框架 + 晚上流程）
- 已完成：`main.js`、`state.js`、`ui.js`、`scenes/Boot.js`、`scenes/Intro.js`
- 待完成：`scenes/Class.js`、`scenes/Charge.js`、`scenes/Result.js`
- **第一件事**：先提交 6 个空场景（FindCar、Ride、Park、Class、Charge、Result），每个只要按 F 能跳到下一个场景就行，这样大家才跑得起来
- 管理 GameState 字段，负责合并代码
- 演示前把 `main.js` 里的 `DEBUG_START` 改回 `null`

### B：玩法程序（早上流程）
- `scenes/FindCar.js`：找车
- `scenes/Ride.js`：骑车（最复杂，要先做）：障碍、血量、坡道耗电、摔倒后按 F 扶车、没电推车
- `scenes/Park.js`：停车

### C：美术和音效
- 按 `assets.js` 的清单做 15 张图和 5 个音效
- 图放 `assets/img/`（png），音效放 `assets/sfx/`（mp3）
- 文件名和清单里的名字一样，尺寸照表，车头朝上
- 每放好一个，就把清单里对应的 `file` 改成 `true`，刷新浏览器就能看到
- 只改 `assets.js` 这一个代码文件

### D：数值、文案、测试
- `config.js` 只改数字，`lines.js` 只改文字
- 用 `DEBUG_START` 直接进某个场景，一个个测，发现 bug 就告诉 A 或 B
- 目标：一次骑行大约 60 秒，4 种结局都能打出来

## 场景流程与交接

```
Boot → Intro → FindCar → Ride → Park → Class → Charge → Result → 回到 Intro（第二天）
```

| 场景 | 谁写 | 结束时更新的数据 | 下一个场景 |
|---|---|---|---|
| FindCar | B | `clock`、`findCarMinutes` | Ride |
| Ride | B | `battery`、`hp`、`hits`、`falls`、`clock` | Park（没电时传 `{ pushing: true }`，推车进场） |
| Park | B | `arriveClock`；停好的时间晚于 8:00 就把 `late` 设为 `true` | Class |
| Class | A | 电量减去 `dayDrain`，时间跳到 `nightClock`（22:40） | Charge |
| Charge | A | `chargeResult`、`chargeGain`、`battery` | Result |
| Result | A | 按"有没有迟到"和"电量是否 ≥ `chargedThreshold`"选 4 种结局之一 | 调用 `nextDay()` 回到 Intro |

4 种结局对应 `lines.js` 里的 `endings`：`ontime_charged`、`ontime_empty`、`late_charged`、`late_empty`。

## GameState 字段

字段名和含义不许改。要新增字段，先在群里说，由 A 改 `state.js`，并同步更新下表。

| 字段 | 含义 | 谁写入 |
|---|---|---|
| `day` | 第几天 | `newGame()` / `nextDay()` |
| `clock` | 游戏内时间，单位"分钟"，可带小数（455 = 7:35） | 所有场景（`UI.tickClock`） |
| `clockPaused` | 弹窗时为 `true`，时钟暂停 | `UI` |
| `battery` | 电量 0–100，唯一跨天保留的数据 | Ride、Class、Charge |
| `hp` | 血量，只在 Ride 使用 | Ride |
| `late` | 是否迟到 | Park |
| `hits` | 被撞次数 | Ride |
| `falls` | 摔倒次数 | Ride |
| `findCarMinutes` | 找车用了几分钟 | FindCar |
| `arriveClock` | 停好车的时刻 | Park |
| `chargeResult` | `'none'` \| `'watch'` \| `'full'` \| `'unplugged'` | Charge |
| `chargeGain` | 今晚充进去多少电 | Charge |

## 协作规矩
- 每人只改自己的文件，避免 git 冲突。
- 气泡、提示、弹窗、切场景、音效都用 `ui.js` 里现成的函数，不要在场景里自己重写：
  - `UI.setup(this)`：每个场景 `create()` 第一行
  - `if (UI.blocked(this)) return;`：每个场景 `update()` 开头
  - `UI.say` 独白气泡、`UI.hint` 底部提示、`UI.choice` 二选一弹窗
  - `UI.fadeTo` 切场景、`UI.sfx` 音效
  - `UI.createClock` / `UI.tickClock` 时钟、`UI.createHud` / `UI.updateHud` 电量和血量
  - 判断按 F 用 `UI.pressedF(this)`，不要直接用 `JustDown`
